# Records

Historical working records: audits, reviewed feedback, decision history and the ideas backlog. They explain why
the setup looks the way it does. They are **not** current policy and are not read during normal task startup. Current
rules live in `instructions/`, `skills/` and the root guides.

Records are kept as written. Do not edit them to match later decisions; add a new record or update the live file instead.

| Record | What it holds |
| --- | --- |
| [decisions.md](decisions.md) | Why each skill or approach was kept, changed or dropped (history up to 2026-11) |
| [friction-log-2026-09-to-11.md](friction-log-2026-09-to-11.md) | Raw friction entries already reviewed and applied |
| [friction-log-review.md](friction-log-review.md) | Per-entry disposition of that friction log |
