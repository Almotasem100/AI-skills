# Friction log

One line whenever something in the setup annoys you, fails, or makes you work around it. Do not fix anything
here; just note it. After 2–3 real tickets, review the list with an agent, apply fixes to the owning file
(skill, contract, profile or guide), then move the reviewed entries to `records/`.

Keep project-specific names out of entries; describe the pattern, not the project.

Format: `YYYY-MM-DD | skill/tool | what happened | (optional) idea`
