# HDC session-closeout profile

This is a tracked, project-specific configuration template for using the portable
[`session-closeout`](../../skills/session-closeout/SKILL.md) skill with HDC. It is not a second session report,
and it is not installed automatically. HDC's canonical project guidance remains in `HDC-documents/README.md` and
`HDC_Modernization_Development_Plan.md` §0a.

The profile was drafted from those HDC rules, the URL-map README, and the functional-documentation header. On
2026-09-30, the owner-approved closeout procedure was added to `HDC-documents/README.md` and the setup progress
was recorded in `HDC-documents/automation/Automation_Planning_Handoff.md`. The profile-aware workflow has not
been tested in a real HDC closeout; HDC's canonical documents remain authoritative.

Keep project-specific destinations and conditions here or in HDC's own guidance—not in the generic skill. When
the profile changes, record the reason and update `docs/roadmap.md` so the copy remains reviewable.
